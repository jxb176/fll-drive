FLL Drive home

Privacy policy

Effective November 1, 2026. FLL Drive is a personal rclone setup operated by GitHub account owner jxb176 for transferring FLL meeting materials between Linux and the owner's Google Drive.

Google Drive access and use

The owner authorizes rclone through Google OAuth. rclone uses the Google Drive API to read file and folder metadata and transfer file contents according to the selected permissions and commands. Depending on those permissions, commands can list, download, upload, modify, or delete files.

Access is determined by the OAuth scopes granted on Google's consent screen. The full Drive scope permits access to all files accessible to the authorized account, except the application data folder; access is not restricted to a single FLL folder. Selecting a folder in rclone does not narrow the OAuth grant. A narrower scope, if selected, limits access according to Google's permissions.

Local storage and transfers

OAuth client credentials and access and refresh tokens are stored in the local rclone configuration on the machine running rclone, outside this public website repository. The owner must protect that configuration and any backups. Transferred files may remain on Linux, in Google Drive, on the laptop, and in backups until the owner removes them. rclone communicates with Google over encrypted HTTPS connections.

Other services and disclosure

The owner may use Codex or other services to prepare or process materials. Files or content made available to those services are subject to their respective policies and the owner's choices. This workflow does not promise that data stays exclusively between Linux and Google Drive. Google user data is used for the owner's file-transfer and materials-preparation workflow, not sold or used for advertising.

This static website does not request OAuth tokens, access Drive, accept file uploads, or include analytics scripts. GitHub Pages hosts it and may process visitor request data under GitHub's privacy statement. Credentials, Drive files, and student information do not belong in this website repository.

Revoking access and deleting data

Visit Google Account third-party connections, select the connection corresponding to this OAuth client, and remove its access. Revocation prevents further authorized access but does not delete copies already transferred. The owner can separately remove local rclone credentials and tokens, backups, and file copies, and delete Drive files and empty the trash when appropriate.

The operator is jxb176. The OAuth consent screen supplies the owner's selected support email. Do not post credentials, private files, or student information in public GitHub discussions.
